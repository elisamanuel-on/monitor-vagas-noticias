Privacidade

Este projeto é o portefólio pessoal da Elisama Manuel. Esta página explica, em português simples, que dados pessoais são guardados quando entras no painel com a tua conta Google, porquê, e como podes pedir para serem apagados.

Que dados guardamos quando entras com a conta Google

Ao clicares em "Entrar" e autorizares no ecrã do Google, recebemos e guardamos apenas três coisas da tua conta: o teu nome, o teu email e a tua foto de perfil pública — os mesmos dados que já partilhas com qualquer site que uses "Entrar com o Google". Nunca vemos nem guardamos a tua password.

Porque guardamos estes dados

Só para saber quem está a usar o painel, e para cada pessoa ver e gerir as suas próprias candidaturas separadamente das dos colegas — é o propósito do login, nada mais.

Onde ficam guardados e quem tem acesso

Tudo fica numa base de dados MongoDB Atlas própria deste projeto. Não é partilhado com mais ninguém, não é vendido, nem é usado para publicidade ou para qualquer outro fim além do funcionamento do próprio painel.

As vagas e notícias não são dados teus

As vagas de emprego e as notícias mostradas no painel são recolhidas automaticamente de fontes públicas (a API da ITJobs e feeds RSS) — não têm nenhuma relação com os teus dados pessoais, são as mesmas para todas as pessoas que usam o Monitor.

Quanto tempo ficam guardados

Os dados da tua conta ficam guardados enquanto a conta existir. Podes pedir para serem apagados a qualquer momento — ver a seguir.
